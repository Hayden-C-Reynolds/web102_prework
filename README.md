# WEB102 Prework – Sea Monster Crowdfunding

Submitted by: **Hayden Reynolds**

**Sea Monster Crowdfunding** is a website for a crowdfunding company that displays information about the games they have funded, including funding status, total contributions, and dollars raised.

Time spent: **~10 hours** spent in total

---

## Required Features

The following **required** functionality is completed:

* [x] The introduction section explains the background of the company and how many games remain unfunded.
* [x] The Stats section includes information about the total contributions and dollars raised as well as the top two most funded games.
* [x] The Our Games section initially displays all games funded by Sea Monster Crowdfunding.
* [x] The Our Games section has three buttons that allow the user to display only unfunded games, only funded games, or all games.

---

## Optional Features

The following **optional** features are implemented:

* [x] Live search functionality that filters games by name as the user types.

## Notes

This project helped reinforce JavaScript fundamentals such as DOM manipulation, event listeners, and array methods like `filter`, `reduce`, and `sort`.  
The most challenging part was implementing live search functionality using input events and understanding how callback functions execute in response to user interaction.
